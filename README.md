# Shivansh Singh — Animated Portfolio

A responsive, experimental portfolio inspired by motion-driven portfolio design. Built with plain HTML, CSS, and JavaScript so it can be hosted on GitHub Pages without a build step.

## Included interactions
- Scroll-triggered section and typography reveals
- Reading progress bar
- Layered orbit/3D-inspired hero artwork with subtle pointer parallax
- Full-screen animated navigation overlay
- Interactive project cards with accessible detail dialogs
- Custom cursor on desktop pointer devices
- Responsive layouts and reduced-motion support

## Files
- `index.html` — page content and metadata
- `styles.css` — layout, visual system, animations, responsive breakpoints
- `script.js` — scroll, navigation, pointer, and project dialog interactions

## Deploy to GitHub Pages
1. Download and unzip this package.
2. Open your existing repository: `https://github.com/shivanshsinghlu24/Portfolio`.
3. Back up the current files first (download a ZIP of the repository or create a branch).
4. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the same folder that currently contains your live `index.html` (usually the repository root). Replace the old files when prompted.
5. Commit the changes to the branch/folder configured in **Settings → Pages** (often `main` and `/ (root)`).
6. Wait for GitHub Pages to rebuild, then visit `https://shivanshsinghlu24.github.io/Portfolio/` and hard-refresh if the old version is cached.

## Personalisation
- Email and social links are already set to the details supplied in the conversation.
- Project descriptions are intentionally honest and label concepts as concepts. Add screenshots, real project links, and measured results as they become available.
- Google Fonts are loaded from a CDN; if offline support is required, replace them with system fonts.

## Notes
- No framework, npm, or build command is required.
- External Google Fonts need an internet connection. The website itself is hosted as static files.
- Check links and content before publishing. This package does not push changes to GitHub automatically.
