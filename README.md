# Shivansh Singh — Animated Portfolio

A responsive, animated portfolio website for a Mechanical Engineering student. Built with plain HTML, CSS and JavaScript; no build tools are required.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling, animated 3D-inspired hero, cards and motion
- `script.js` — mobile navigation, scroll reveal and active navigation

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your actual email address.
2. Replace the generic LinkedIn and GitHub links with your real profile URLs.
3. Add your real CAD screenshots and completed project details. The gearbox and FEA cards are clearly marked **Planned** and should not be presented as completed work.
4. Only add certificates you have actually earned.

## Publish free with GitHub Pages (tablet-friendly)
1. Sign in or create an account at https://github.com/.
2. Create a new **public** repository, for example `shivansh-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and optionally `README.md` to the repository root. On GitHub's website, use **Add file → Upload files** and select the files.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then press **Save**.
7. Wait a few minutes. GitHub Pages will show the published website URL in the Pages settings. It will usually look like `https://YOUR-USERNAME.github.io/shivansh-portfolio/`.
8. Open that URL on your tablet and test the navigation, contact links and layout.

## Editing later
Edit `index.html` to change text and links. Edit `style.css` to change colors and appearance. GitHub Pages automatically republishes after you commit changes.

## Notes
- Google Fonts are loaded from Google Fonts; if the connection is unavailable, fallback fonts are used.
- This site has no backend or contact form. The email button opens the visitor's email app.
- Do not upload private contact details you do not want public.
